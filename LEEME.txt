CÓMO ABRIR
- Doble clic en index.html (funciona desde file://, sin servidor ni Internet).
- También sirve en cualquier hosting estático (copiar la carpeta tal cual).
ACCESO AL PORTAL (dos modos; se elige solo según js/firebase-config.js)
- MODO FIREBASE (cuando js/firebase-config.js tiene apiKey y projectId):
  · Pantalla de entrada «SuperProfe · Alumnos» con dos opciones:
      «Soy alumno»: código de grupo (p. ej. FARO-472) + número de lista (1-40). Sesión ANÓNIMA de
                    Firebase: no se pide ni se guarda nombre ni correo del alumno.
      «Soy profesor»: «Iniciar sesión con Google» (ventana emergente; si el navegador la bloquea,
                    se usa la redirección). Solo tiene rol de profesor el correo fijado en las reglas
                    de Firestore (y los que añada a config/profesores).
  · Panel del profesor (index.html#panel, solo visible para el profesor):
      #panel/grupos      crear grupos (asignaturas, apartados, horario opcional), código aleatorio
                         legible, «Reiniciar código», «Cerrar/Abrir acceso», «En grande» para proyectar.
      #panel/conectados  grupo, nº, dónde está, desde cuándo, última señal (latido cada 60 s y al
                         cambiar de página, como mucho cada 15 s), «Expulsar».
      #panel/entregas    entregas de Circuitos (montaje + respuestas + comprobación) y de proyectos
                         ESP32 (hecho + informe); filtros, abrir el montaje en el simulador en modo
                         lectura (#eee/circuitos/revision), nota y comentario, exportar CSV (;).
      #panel/limpieza    borrar sesiones antiguas y borrar entregas (de un grupo o de todos).
  · El alumno ve «Entregado» y, cuando la hay, la nota y el comentario (solo los de su sesión).
  · Validación EN EL SERVIDOR con reglas de Firestore (sin Cloud Functions; plan Spark gratuito):
      codigos/{CÓDIGO}  el código es el ID del documento: se puede leer uno conociéndolo, NO listar.
      sesiones/{uid}    {codigo, grupo, numero, pagina, desde, latido, revocada}. Solo se acepta si el
                        código está activo, es de ese grupo y (si lo hay) dentro del horario.
      entregas/{uid_grupo_nº_práctica}  solo con sesión válida; el alumno no puede ponerse nota ni
                        leer entregas ajenas. Reiniciar código = borrar el documento viejo y crear
                        otro: las sesiones con el viejo dejan de valer al instante. Expulsar = revocada.
    Las reglas (comentadas) y sus pruebas NO están en este repositorio: tools/firebase/.
  · Firebase va empaquetado en js/portal-fb.js (sin CDN). Se compila con: cd tools && npm run build
  · Límites del plan gratuito a tener en cuenta: 100 cuentas anónimas nuevas por hora y por IP (todo
    el instituto suele salir por una IP; la web reutiliza la sesión anónima de cada navegador y solo
    crea otra al pulsar «Salir» o tras una expulsión) y 20 000 escrituras/50 000 lecturas al día.
- MODO CÓDIGO DE CLASE (configuración de Firebase vacía; respaldo):
  · La web pide un «Código de clase». Si es correcto, entra y el navegador lo recuerda. «Salir» lo olvida.
    No distingue mayúsculas ni espacios. Solo se guardan hashes en js/acceso-config.js. Para cambiarlo:
      cd tools && node set-codigo.mjs "palabra-palabra-00" ["otro-codigo-12"]
    (regenera los hashes y sube «version»; no escribas el código en claro en el repositorio).
- NOTA HONESTA SOBRE LO QUE PROTEGE: GitHub Pages sirve archivos estáticos y públicos. Quien conozca las
  rutas puede descargar el HTML, el JavaScript, las imágenes y los .ino aunque no tenga código. El control
  de acceso protege el USO del portal: quién entra y desde dónde, las entregas, las notas y el panel del
  profesor (esos datos sí están protegidos por las reglas de Firestore).
- La web incluye <meta name="robots" content="noindex, nofollow"> y un robots.txt
  que bloquea el rastreo, para que no la indexen los buscadores.
- Al abrir (después de entrar) se ve la PORTADA (ciclo, asignatura, profesor) con el botón «Entrar».
- «Entrar» lleva a CURSO: las asignaturas de este curso escolar (tarjetas). El profesor tiene además la
  BIBLIOTECA (#biblioteca): todas las asignaturas trabajadas, también de otros años, con «Añadir al curso»;
  en Curso, «Quitar del curso» la saca de este año (y de sus grupos) sin borrar nada.
  La tarjeta «Equipos eléctricos y electrónicos» abre sus APARTADOS:
  «ESP32» (los 8 proyectos de siempre) y «Circuitos» (laboratorio 3D de protoboard).
- Direcciones (hash):

    index.html#asignaturas  Curso: asignaturas de este curso escolar
    index.html#biblioteca   Biblioteca: todas las asignaturas (solo el profesor)
    index.html#eee          Equipos eléctricos y electrónicos: elegir apartado (ESP32 / Circuitos)

AÑADIR UNA ASIGNATURA (para el futuro)
- Editar tools/src/subjects.js (array SUBJECTS: id, codigo, nombre, profesor, icon, desc, active)
  y recompilar js/app.js con esbuild. Hoy solo existe «eee»; se muestra además una tarjeta «Próximamente».
- Apartados de una asignatura: tools/src/subjects.js, objeto APARTADOS (id, nombre, icon, color, desc, tags, active).
- Recompilar: cd tools && npm run build   (esbuild; los .ino se cargan como texto)

LABORATORIO DE CIRCUITOS (apartado «Circuitos»)
- Código propio en tools/src/circ/ (three.js local, sin conexión). Estilos: css/circuitos.css
  (paleta azul petróleo / turquesa / ámbar).
- Protoboard 3D (30 columnas, carriles + y −), arrastrar y soltar con encaje, girar (R), borrar (Supr),
  deshacer/rehacer (Ctrl+Z / Ctrl+Y), cables clic-a-clic con colores 0–9, vista desde arriba (T).
- Componentes: pila 9 V, portapilas 2×AA y 4×AA, fuente regulable, resistencia (valor E12 y código de colores),
  LED (4 colores, polaridad, se funde), bombilla, pulsador, interruptor, conmutador, potenciómetro, LDR,
  zumbador, motor DC, condensador, diodo y polímetro (V, A, Ω) con puntas.
- Simulación por análisis nodal modificado (MNA) en continua, LED/diodo por tramos, avisos de cortocircuito,
  LED fundido, bombilla fundida, fusible del polímetro y resistencia que se calienta.
- 9 prácticas guiadas (objetivo, material, esquema, pasos con marca en el sitio exacto, comprobación automática,
  preguntas de cálculo, «Ver solución») + modo libre. Guardado automático en el navegador y exportar/importar .json.
- Verificación automática: tools/circ_test.mjs (playwright-core + Chrome headless).
- Verificación del acceso: tools/acceso_test.mjs (código de clase), tools/firebase/test/reglas.test.mjs (reglas
  de Firestore con el emulador, incluidos ataques) y tools/e2e/fb_e2e.mjs (flujo completo con los emuladores de
  Auth + Firestore).

Las 8 lecciones compilan sin errores. Librerías: LiquidCrystal I2C 1.1.2, ESP32Servo 3.2.1,
Adafruit SH110X 2.1.15, Adafruit GFX 1.13.0, Adafruit BMP280 3.0.0 (+ Unified Sensor, BusIO).
P8 usa ledcAttach(): requiere core esp32 3.x.
